《湖景小屋合集》子非鱼AI汉化补丁 v1.0

适用于 **Steam Windows Build 2415026**。覆盖已提取的61条常规文本（476个资源字段）及170处图片文字，保留原图并叠加中文。覆盖数量不代表全游戏无漏字。

**F7** 切换轻底／无底／清晰底并记住选择；**F8** 显示／隐藏中文。进入菜单后短暂提示这两个快捷键。
