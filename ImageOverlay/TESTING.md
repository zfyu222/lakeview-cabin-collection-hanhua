# 本地汉化候选版：用户实机检查

本次由代理完成文件处理、翻译审校、编译、静态预览和安装；没有启动游戏或控制桌面。静态通过不能代替实机通过，尚未对外发布。

2026-10-24反馈：用户已测试旧样式，认为“问题不大”，但灰底过浓。本次只调整显示样式，尚待复测。默认普通标签25%不透明、便条40%，中文加细黑描边。按F7循环“轻底→无底→清晰底”，自动记忆；清晰底为普通55%/便条65%。F8仍开关中文。可先在报纸和一张长便条上比较，选择原画与中文阅读最合适的一档。

1. 从Steam正常启动游戏，检查中文字体有无方框、乱码或异常小字。先使用1920×1080或你平常的分辨率；低分辨率的世界场景标语须另看是否拥挤。静态大场景预览按约1920像素宽渲染，不能当作所有分辨率均通过。
2. 暂停菜单、确认框和操作提示：中文应与按钮含义对应。按F8切换中文覆盖层与原图，确认原图仍在、切换正常。
3. 再打开之前截图的报纸：应看到“湖景邮报”“婴儿绑架案仍在继续！”“警方一筹莫展”。检查便条、日记阅读界面的长句和换行。
4. 到达相关场景时检查：两个EXIT标牌应显示“出口”，不再误显示“宿舍”或“医疗舱”；监视器口号、雪花电视、登机提示、广告和厨房菜单应出现中文。SPACE与PSYCHOS标题分别显示对应词，不能重复两遍完整标题。
5. 检查非文字美术：出售牌支架、骷髅动画帧不应凭空出现文字；厕所涂鸦保留RED署名、心形字母和数字，只有可读语句加中文。解谜字母、号码、按键和故障残字刻意保留，不当作普通漏译。

不必为了检查而立刻重玩所有章节。遇到问题时记录章节/场景、分辨率、原图文字、F8切换前后的现象；需要图像证据时可直接在聊天附图。未实际到达的隐藏场景保持未验证。

如果在游戏中遇到SECURITY、ARMORY等仍为英文的具体牌子，请记录场景：资源图集中部分标签没有对应导出的Sprite切片，当前未找到可靠显示绑定，译文虽已整理，但没有误贴到其他精灵。COMBO图集未引用区、极淡电视帧及不能辨认的装饰文字同样保留在覆盖报告中，不能宣称这些都已汉化。

出现异常可退出游戏后运行项目根的 `deploy_patch.py --restore` 恢复原版备份；脚本会校验哈希。不要在游戏运行时覆盖DLL。
